# Веб-резюме · Алексей Булатов

Современная одностраничная версия резюме с переключением языков (RU/EN) и скачиванием PDF.

---

## Быстрый старт

### 1. Залить в GitHub

1. Создай новый репозиторий на GitHub (например, `bulatov-resume`)
2. Распакуй этот архив в локальную папку
3. В файле `vite.config.js` поменяй `base: '/bulatov-resume/'` на имя своего репозитория, например `base: '/my-cv/'`
4. Залей всё в репозиторий:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВОЙ_USERNAME/ТВОЙ_РЕПО.git
git push -u origin main
```

### 2. Включить GitHub Pages

1. Зайди в свой репозиторий на GitHub
2. **Settings** → **Pages**
3. В разделе **Source** выбери **GitHub Actions**
4. Готово! После каждого push в main сайт будет автоматически собираться и деплоиться

Через 1–2 минуты сайт будет доступен по адресу:
```
https://ТВОЙ_USERNAME.github.io/ТВОЙ_РЕПО/
```

## Как редактировать тексты (через GitHub, без кода)

Все тексты резюме лежат в **одном файле**: `src/content.json`

### Пример: поменять номер телефона

1. Открой репозиторий на GitHub
2. Зайди в `src/content.json`
3. Нажми на иконку карандаша (Edit)
4. Найди строку `"phone": "+7 (916) 912-72-90"` и поменяй
5. Прокрути вниз → **Commit changes**
6. Через минуту сайт обновится

### Что можно так редактировать
- Все тексты на двух языках (RU и EN)
- Название должности, место жительства, контакты
- Описание мест работы
- Списки навыков
- Образование, языки

## Как добавить сертификаты

1. Положи PDF-файлы сертификатов в папку `public/certificates/`
   Например: `public/certificates/yandex-direct.pdf`

2. В файле `src/content.json` найди секцию `"certificates": []` (есть в обоих языках — `ru` и `en`)

3. Добавь записи. Пример:

```json
"certificates": [
  {
    "title": "Специалист по Яндекс Директ",
    "issuer": "Яндекс",
    "year": "2024",
    "file": "yandex-direct.pdf"
  },
  {
    "title": "Google Analytics 4",
    "issuer": "Google",
    "year": "2023",
    "file": "ga4.pdf"
  }
]
```

Поле `file` опциональное — если убрать, карточка просто не будет кликабельной.

После пуша на сайте появится секция «Сертификаты» с кликабельными карточками.

## Как добавить рекомендации

В `src/content.json` найди `"recommendations": []`. Пример:

```json
"recommendations": [
  {
    "text": "Алексей — один из самых самостоятельных маркетологов, с которыми мне доводилось работать. Запускал сложные performance-кампании от и до, не теряя при этом стратегического видения.",
    "author": "Иван Иванов",
    "role": "Директор по маркетингу, Corona Travel"
  }
]
```

Если массив пустой — секция вообще не отображается. Появится автоматически, как только добавишь первую запись.

## Локальная разработка (опционально)

Если хочешь проверить изменения локально перед публикацией:

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173/bulatov-resume/`

Для сборки production-версии:
```bash
npm run build
```

## Если нужна полноценная админка с формами

Этот проект готов к подключению **Decap CMS** (бесплатная админка для GitHub-сайтов). Тогда вместо редактирования JSON будет визуальная форма с полями. Если соберёшься — могу добавить позже, для этого нужно будет завести аккаунт на Netlify (для аутентификации через GitHub OAuth).

Текущий вариант (правка JSON через GitHub-интерфейс) — самый простой и не требует ничего настраивать.
